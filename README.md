# Actuarial-Modelling

This repository contains R code solutions for the MTH1000 Class Test (18 November 2025).

## Contents

- **class_test_solutions.R** - Complete solutions to all 4 questions
- **MTH1000 Class Test 2025 - 2026.pdf** - Original test questions
- **markov_jump_model_plot.png** - Visualization output
- **SOLUTIONS_SUMMARY.md** - Detailed summary of results

## Usage

Run the complete solution:
```r
Rscript class_test_solutions.R
```

See SOLUTIONS_SUMMARY.md for detailed results and explanations.
